# Faut-il acheter ce terrain ?

Un outil qui aide à décider si on achète un terrain pour construire.

Il estime la chance d'avoir le permis, la valeur du terrain et le coût des travaux en plus, puis conseille d'acheter, de négocier ou d'éviter.

J'ai travaillé sur 6 000 terrains simulés, avec des valeurs proches de la réalité.

Sur 1 200 terrains de test, l'outil gagne 1,6 M€ au total alors qu'acheter tous les terrains en perd 19,4.

Les données sont simulées, la suite serait d'utiliser les vraies ventes de terrains (base DVF).

Pour le lancer, installer les dépendances avec `pip install -r requirements.txt` puis ouvrir `notebooks/analyse_parcelles.ipynb`.
